!TOPIC 260 NetBIOS
The word NetBIOS stands for Network Basic Input/Output System. It is an
application program interface (API) that supports data exchange between two
workstations on a network. NetBIOS was introduced by IBM in 1984, and
is in widespread use today. It has become an industry standard protocol and
has been implemented by most modern microcomputer network operating
systems. As such, programs written using NetBIOS services will run
unmodified on a wide variety of networks.

The NetBIOS unit implements the NetBIOS services for use in Turbo
Pascal programs. This unit supports NetBIOS name, datagram and session
services.

As of version 5.23, NetBIOS may be used with Turbo Pascal for Windows, under
Windows 3.0 or later running in Standard or Enhanced mode. There are minor
differences in the calling sequences of many NetBIOS routines when used
under Windows. Such headers are listed separately after the DOS calling
sequence for the affected routines. There are also a few new Windows-specific
types and procedures, which appear under the Windows declarations topic below.

  0261Datagram services              0265Declarations
  0262Miscellaneous                  0263Name services
  0264Session services               0293Windows declarations
;

!TOPIC 291 NCB
!NOINDEX
type
  NCB  = record
           Command     : Byte;    {the NetBIOS command}
           RetCode     : Byte;    {the return code}
           LSN         : Byte;    {the local session num}
           NameNum     : Byte;    {the NetBIOS name table num}
           Buffer      : Pointer; {point to data buffer}
           BufLen      : Word;    {length of the data buffer}
           CallName    : CallNameType;  {The local name}
           Name        : CallNameType;  {the remote name}
           RTO         : Byte;    {Receive Time Out}
           STO         : Byte;    {Send Time Out}
           PostRoutine : Pointer; {the post event routine}
           LanaNum     : Byte;    {the LAN adapter number}
           CmdComplete : Byte;    {the command complete flag}
           Reserved    : Array[1..14] of Byte; {scratch}
         end;

The NetBIOS control block. This 64 byte record structure is the heart of
all NetBIOS requests.

The 0260NetBIOS unit manages most of the fields of the NCB for you. The
only fields of concern to you are CmdComplete and RetCode. CmdComplete
contains a value of $FF when the command associated with the NCB is still
pending. When the command is complete, RetCode will have a zero to
indicate success or an error code.

See also:  0289NBECommandPending  0290NetBIOS error codes
;
